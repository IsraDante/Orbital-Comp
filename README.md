# Orbital Comp (VST3 / AU) — by Dante Ramos

Compresor con Threshold, Ratio, Attack, Release, Mix, Output, Bypass y estilo Galaxy / Neón.

## Cómo compilarlo (igual que la reverb)
1. Crea un repositorio nuevo en GitHub y sube TODO el contenido de esta carpeta (incluida la carpeta oculta `.github`).
2. Ve a la pestaña **Actions**: la compilación arranca sola (unos 10-15 min).
3. Al terminar, descarga el artefacto **OrbitalComp-windows-latest** (o macos).
4. Copia `Orbital Comp.vst3` a:
   - Windows: `C:\Program Files\Common Files\VST3\`
   - Mac: `/Library/Audio/Plug-Ins/VST3/`
5. En Cubase: Studio > VST Plug-in Manager > Rescan. Aparece en Dynamics como "Orbital Comp".
